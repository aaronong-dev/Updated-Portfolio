# Aaron Ong — Portfolio

My personal portfolio website, designed to showcase who I am, the technologies I work with, and the projects I’ve built.

The website draws inspiration from Apple and macOS, combining familiar interface elements with playful interactions to create a portfolio that feels personal and unique.

## Live Website

Visit the portfolio at [aaronong.dev](https://aaronong.dev)

## Features

* Apple and macOS-inspired interface
* Responsive design for desktop and mobile devices
* Overview of my technical skills and experience
* Selected software and web development projects
* Client work and professional experience
* Interactive message feature inspired by iMessage
* Rate limiting to help prevent message spam
* Smooth animations and interactive elements

## Built With

* [Next.js](https://nextjs.org/)
* [React](https://react.dev/)
* [TypeScript](https://www.typescriptlang.org/)
* [Tailwind CSS](https://tailwindcss.com/)
* [Vercel](https://vercel.com/)

## Getting Started

To run this project locally, clone the repository and install its dependencies.

```bash
git clone https://github.com/YOUR-USERNAME/YOUR-REPOSITORY.git
cd YOUR-REPOSITORY
npm install
npm run dev
```

Open http://localhost:3000 in your browser to view the website.
